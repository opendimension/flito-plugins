# My day

1. Use `list_tasks` for the user's overdue tasks and the ones due in the next day.
2. Use `get_recent_activity` for the latest emails and calls across the workspace.
3. Use `find_deals` with openOnly for the deals closing this week.
4. Put together a short, ordered plan for today: what to do first and why, with links.
