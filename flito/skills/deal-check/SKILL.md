# Deal check

1. Find the deal with `search` (types deal), or with `find_deals` for a company.
2. Use `check_deal` for it.
3. Tell the user its stage, amount and close date, its health and each flag in plain words, where its quotes stand, and the two or three things to do next, with links.
4. If a follow-up task or email would help, offer it. Make it only after the user says yes.
